# Public Web Application (`apps/web`)

`apps/web` is the public-facing, read-only website for Sierra Leone Grammar School. It provides modern, responsive, accessible, and content-led communication for prospective students, parents, alumni, and the broader community.

---

## Target Audience & Objectives

- **Prospective Students & Parents**: Admissions requirements, scholarships, bursaries, fee structures, sixth form info.
- **Current Students & Staff**: Life at SLGS, academic programs, house system, sports, clubs, term dates.
- **Alumni & Community**: School history, leadership, news journal, photo galleries, contact information.

---

## Navigation & Information Architecture

The website is structured into 10 primary navigation modules:

1. **Home**: Institutional landing page featuring school highlights, news summaries, upcoming events, and headmaster welcome.
2. **About SLGS**: History, vision, governance, leadership, school song, and facilities (`/about`).
3. **Admissions**: Entry requirements, application procedures, scholarships, uniform guidelines, and fee details (`/admissions`).
4. **Academics**: Curriculum overview, STEM lab, computing lab, library facilities, and examination schedules (`/academics`).
5. **Life at SLGS**: House system, sports activities, school band, pastoral care, and daily routines (`/life`).
6. **Parents**: Parent-Teacher Consultations (PTC), school store information, and academic calendars (`/parents`).
7. **News & Journal**: Published articles and journal posts produced by school clubs and staff (`/news`, `/news/:slug`).
8. **Events**: Publicly scheduled school events, ceremonies, and athletic meets (`/events`, `/events/:slug`).
9. **Gallery**: Moderated photo galleries and event photo albums (`/gallery`, `/gallery/:slug`).
10. **Contact**: Location map, administrative contact info, and public inquiries (`/contact`).

Announcements are an editorial route (`/announcements`, `/announcements/:slug`) linked from published homepage notices.

## Data Architecture & Security Barrier

To guarantee that private school data can never be exposed through the public website:

- **Security-Barrier Views**: `apps/web` queries **only** PostgreSQL views in the `public_content` schema (`page`, `article`, `event`, `announcement`, `gallery`). These views filter `WHERE state = 'published' AND published_at IS NOT NULL`.
- **Read-Only Database Role**: Queries execute under the restricted `slgs_web` database user role.
- **Data Transfer Objects (DTOs)**: Data access is mediated through `@slgs/public-content`, enforcing runtime Zod validation and returning DTOs that exclude workflow states, internal identities, audit history, and private media keys.
- **In-Process Caching**: `withPublicContentCache` applies a 60-second in-memory cache per Web server process to bound database re-queries.

```
                          ┌───────────────────────────┐
                          │   apps/web Application    │
                          └─────────────┬─────────────┘
                                        │
                                        ▼ (Public DTOs & Cache)
                          ┌───────────────────────────┐
                          │   @slgs/public-content    │
                          └─────────────┬─────────────┘
                                        │
                                        ▼ (slgs_web DB Role)
  PostgreSQL Schema: public_content (Security Views: state = published & published_at IS NOT NULL)
```

## Canonical Path & SEO Integration

Every published item includes a canonical path (`canonicalPath`) that dictates its public URL:

- **Head Metadata**: Route loaders call `detailHead` to emit absolute canonical links `<link rel="canonical" href="http://slgs.edu.sl/news/my-story" />` and `<meta property="og:url" content="http://slgs.edu.sl/news/my-story" />`.
- **Default Canonical Path**: If an explicit path was omitted during creation, `defaultCanonicalPath` auto-generates the path (`/news/:slug`, `/events/:slug`, `/gallery/:slug`, `/announcements/:slug`, `/:slug`).
- **Dynamic Sitemap (`/sitemap.xml`)**: Queries published content DTOs and emits XML sitemaps incorporating all active canonical URLs.

## Operational Configuration

- **Development Port**: `http://localhost:3001`
- **Canonical Origin**: `http://slgs.edu.sl`
- **Environment Variables**:
  - `PUBLIC_SITE_URL`: Configures canonical URLs, Open Graph tags, sitemap entries, and `robots.txt`.
  - `WEB_DATABASE_URL`: Connection string scoped strictly to the `slgs_web` PostgreSQL user.
