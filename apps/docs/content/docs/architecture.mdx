# System Architecture

The SLGS platform contains an anonymous Public Web and authenticated CMS in a TypeScript, pnpm and Turborepo monorepo.

```text
apps/web → public_content security-barrier views → published CMS content
apps/cms → identity + cms schemas → private Cloudflare R2
```

`apps/web` uses the least-privileged `slgs_web` role and cannot read identity or CMS operational tables. `apps/cms` uses Better Auth, the `slgs_cms` role and server-side authorization for users, memberships, clubs, roles, content, workflow, media and audit.

Shared packages provide database access, authentication, CMS-only authorization, editorial domain behavior, public DTOs, UI and Zod validation. The R2 bucket remains private; uploads and downloads use short-lived, server-authorized presigned URLs.

The discontinued school-administration product is not an active application, package, schema or runtime role. Historical migrations and deprecated decision records remain for traceability.
